Images for the mod manager, drawn with your game's icons. Keep the game running with a save loaded. In Chrome or Edge, open DevTools (F12), select #icon or #banner in the Elements panel, press Ctrl+Shift+P and run Capture node screenshot. Save them as res/icon.png and res/banner.png. Options: ?icon=Lantern (any icon name or item number), &theme=midna.
